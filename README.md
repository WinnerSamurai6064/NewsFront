# Newsfront

Newsfront is a Vercel-ready AI-assisted news website.

## Stack

- Next.js
- TypeScript
- CSS modules/global CSS
- Vercel deployment
- MCP-ready API structure

## Visual direction

- Deep news blue
- Dull white/off-white text
- Standard newsroom heading and paragraph formatting
- Editorial card layouts

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Planned AI journalist layer

The project is prepared for an MCP-style AI journalist workflow:

- collect trusted sources
- generate article drafts
- auto-publish low-risk categories
- keep source/citation metadata
- expose controlled CMS tools through API routes
